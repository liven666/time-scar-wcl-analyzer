# 时光战痕｜时光服 WCL 分析台

浏览器端本地解析 `WoWCombatLog.txt` 的团队日志分析工具。项目参考了
NGA 帖子“本地解析日志，30 秒生成可分享的 WCL 口径伤害统计”的产品思路。

## 当前能力

- Web Worker 分块读取大体积战斗日志，解析时不阻塞页面，原始文本不上传服务器
- 支持持续写入日志的增量实时解析：原生文件授权或 localhost 只读路径模式
- 兼容标准日志与高级战斗日志 v9 的单位快照字段
- 识别 Boss 场次、击杀状态、伤害目标、玩家、宠物、图腾和守护者归属
- 按“Boss → 角色 → 目标”切换完整战斗复盘视角
- 在统一时间轴展示 Boss 血量快照、输出/治疗/承伤峰值和每个技能事件
- 支持鼠标与触控按住时间轴横向拖动，并可调整每秒像素缩放
- 将玩家技能按行放入共享时间尺，上方显示施法图标、下方显示 Buff 区间，并保留 1.5 秒公共 CD 网格
- 每条血量、强度、技能、Buff、Debuff 和关键事件轨道均可点开查看汇总与明细
- 展示个人 Buff、目标 Debuff 的起止区间、层数与覆盖率
- 保留施法开始/成功/失败、未命中、打断、驱散、死亡和资源变化
- 点击技能图标立即弹出详情，查看伤害/治疗/吸收、暴击、未命中、格挡、偏斜、躲闪、Boss 绝对血量与百分比
- 为 DPS、坦克、治疗分别计算输出断档、承伤尖峰、减伤覆盖、过量治疗等复盘指标
- 在“仅 Boss / 全日志 / 全局小怪”之间即时切换
- 调整单场权重，手动排除 Boss、失败场次和指定目标
- 计算自定义 DPS 合格线、近远程前三、DPS 不过坦和小怪尾位
- 统计破甲、精灵之火、恶魔契约覆盖率
- 识别开怪人和临时增伤光环
- 导出 CSV，并将汇总结果压缩进可分享链接
- 支持深色 / 浅色模式切换并记住本机选择
- 展示时光服 P1-P11 团本阶段表，并区分官方公告与游戏内成就预览

## 本地运行

需要 Node.js `>=22.13.0` 和 pnpm。

```bash
pnpm install
pnpm run dev
```

`pnpm run dev` 会同时启动网页和仅绑定 `127.0.0.1:3001` 的只读实时日志助手。
Chrome / Edge 优先使用浏览器原生持续文件授权；内置浏览器可在“本地路径模式”中
填写 `WoWCombatLog.txt` 的绝对路径。助手只允许 localhost 页面读取 `.txt/.log`，
按文件偏移量返回新增字节，不会写入或上传日志。

构建与测试：

```bash
pnpm test
pnpm run lint
```

部署到其他平台时，请查看 [部署说明](./DEPLOYMENT.zh-CN.md)。推荐使用能够常驻 Node.js
进程的平台或 Cloudflare Workers；纯静态托管无法提供 SSR 与技能图标代理接口。

## 口径说明

解析器可直接读取 `WoWCombatLog.txt` 中的 Boss 开始/结束、伤害、治疗、过量、
吸收、施法成败、光环和召唤关系；高级日志中的 `Pet-*`、`Creature-*` 宠物、
图腾与守护者会优先通过快照主人 GUID 归属。当前回归基准包含一份 233 MB、
752,800 行、16 场 Boss 的高级日志：约 7.7 秒生成 374,213 个详细事件和
53,994 段光环区间，Node.js 回归时堆内存约 179 MB。

职业/职责、开怪人、关键光环、常见爆发/减伤 Buff 和临时增伤属于通用启发式识别，
不承诺覆盖每个 Boss 的 WCL 专属规则。没有直接血量字段的施法事件会显示邻近快照
及时间差，不伪造精确血量。严谨排名、百分位和官方 Boss 口径仍应以 Warcraft Logs
为准。
